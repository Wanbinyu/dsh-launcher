# dsh-launcher v0.5.0

## 插件与 Skills 推荐

- 新增“你主要用 DeepSeek Harness 做什么？”本地推荐向导，提供新手入门、日常编程、API 调试、成本控制、长任务观察和完整体验六种方向。
- 新安装或升级到新启动器版本后只显示一次；同一版本不会重复弹出。
- 托盘新增“小功能 → 插件与 Skills 推荐”，可随时重新打开并更改方向。
- 推荐结果显示用途、原因、Harness 兼容范围，并可勾选后复制固定 GitHub Release 安装命令。
- 托盘“小功能”同时提供 DSH Toolbox 入口。

## 稳定性与隐私

- 推荐规则随 EXE 内置，不调用大模型或远程推荐服务。
- 不读取 Harness 会话、工作区、提示词、回复、路径、文件或密钥，也不添加遥测。
- 使用方向和版本提示标记仅保存在 `%LOCALAPPDATA%\dsh-launcher\recommendations.json`。
- 不执行静默安装；用户需要检查并主动运行复制的命令。
- 当前只推荐带 bundle 清单和固定 Release 安装地址的六个已验证插件。

## English summary

Version 0.5.0 adds a private, rule-based Plugin & Skills guide under the tray Utilities menu. It asks for a workflow once per launcher version, keeps the answer locally, recommends verified bundles, and copies pinned install commands without silently installing anything.
