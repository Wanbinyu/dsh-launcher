# dsh-launcher v0.5.2

- 更新六个社区插件到本次兼容性修复版本。
- 插件推荐检查当前 Harness 版本；未验证或无法识别时禁止勾选，避免安装后模块加载失败。
- 本次插件包已验证 Harness 0.1.5-rc.2 和 0.1.1-rc.2。
- Windows 编译、单元测试、启动冒烟和安装包校验；Android 版本保持 0.1.2。

下载 dsh-launcher-setup.exe 安装，或使用 dsh-launcher.exe 便携版。两者均提供 SHA-256 校验文件。
Launcher 更新不会自动替换已安装插件；请在插件向导中选择适配当前宿主的修复版本。
