# dsh-launcher v0.5.3

- 自有六个插件安装包适配 Harness 0.2.1-alpha.3，并接受 0.2.0-rc.2。
- 仍允许已验证的 0.1.1-rc.2 和 0.1.5-rc.2。
- 其他第三方插件不加入这次宿主版本，未验证的宿主上仍会显示暂不安装。
- Windows 编译、单元测试、启动冒烟和安装包校验；Android 版本保持 0.1.2。

下载 dsh-launcher-setup.exe 安装，或使用 dsh-launcher.exe 便携版。两者均提供 SHA-256 校验文件。
启动器更新不会自动替换已安装插件；请在插件向导中选择适配当前宿主的版本。
